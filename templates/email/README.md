# 邮件模板

`welcome.html` 是迁移上线后可复用的欢迎邮件样式，包含站点入口、邮箱验证码登录说明和用户昵称。白底、玫红配色，使用表格布局和内联样式，适合桌面及手机邮件客户端。

该文件使用 Go 标准库 `html/template` 的变量语法，渲染时传入：

| 字段 | 含义 |
|---|---|
| `Nickname` | 当前收件人的昵称 |
| `BaseURL` | 本次部署的 HTTPS 站点地址，例如 `https://wiki.example.com` |

使用 `html/template` 渲染，让昵称和链接按所在上下文转义。站点地址应来自受控的部署配置。示例主题为“鸟托邦 Wiki 新站上线，欢迎回来看看”；发送前按实际迁移状态调整正文，尤其确认旧站内容已迁移、旧站仍保留的描述准确。

这只是模板资源，不会自动群发。发送邮件时另外提供纯文字正文，逐位设置收件人，避免通过抄送暴露成员邮箱。

真实收件名单、发件凭据、发送脚本、回执和成员头像不属于本目录，也不应纳入 Git。
