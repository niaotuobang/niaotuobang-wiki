# 本地实现与验证记录

更新于 2026-10-24，对应 [RFC 0001](rfcs/0001-lightweight-wiki-go-vue.md)。本记录只包含通用实现说明和虚构数据验证结果。实际云资源、部署参数及生产资料不进入公开仓库。

## 当前产物

已提供可在本地运行的 Go + Vue 3 + SQLite 版本。Go 嵌入构建后的 Vue，统一提供网页、`/api/v1`、媒体及健康检查；运行发行包不需要 Node.js。页面参考 Matterwiki 的留白、大标题、正文和右侧信息栏；首页及 Tag 页保留左侧导航，手机使用折叠导航。

人物、事件和普通故事均为同一种文章，类型仅通过普通 Tag 表达。所有 Tag 都有列表页，是否出现在导航可单独设置。文章支持富文本、图片视频引用、草稿、修订版本、内部文章链接和反向链接，以及可选的年／月／日发生时间。时间线使用发生时间，文章列表使用更新时间。

实现还包含本地账号、邀请及成员角色、回收站、流式本地媒体与 OSS 直传适配器、备份恢复、完整 JSON／Markdown 导出、Matterwiki 规范化导入工具。导入默认预演，实际应用须显式指定 `--apply`。没有自动抓取旧站或迁移生产资料。

M0、M1 已有本地闭环；M2 的实现已提供，浏览器媒体和真实部署验证尚未全部完成，因此不宣称第一版验收全部通过。M3 AI 辅助、M4 原生小程序与微信／手机号／邮箱绑定尚未实现。未来小程序独立构建发布，复用 Go API；网页静态资源由 Go 承接。

## 合成文本负载

本机 ARM64 Docker，容器限制 1 CPU、1 GiB，SQLite 持久目录。基线 10,000 篇虚构文章，4 个并发读客户端与 1 个写客户端；共 200 次列表、200 次中文搜索和 20 次发布，约 21.88 秒完成。请求成功，发布后可见文章 10,020 篇。

| 操作 | P50 | P95 | 最大 |
| --- | ---: | ---: | ---: |
| 列表 | 127.85 ms | 334.81 ms | 373.26 ms |
| 搜索 | 330.12 ms | 441.51 ms | 454.86 ms |
| 发布 | 8.64 ms | 223.74 ms | 277.00 ms |

内核 cgroup 记录测试前内存约 17.66 MiB，结束约 20.29 MiB，容器生命周期峰值约 25.96 MiB；包含健康检查和测量辅助进程。这是单机合成文本测试，不是生产容量承诺，也不包含云网络或视频播放负载。

备份恢复后的库包含 10,060 篇文章及 10,060 个版本（含前次测试留下的已软删除文章），4 个 Tag；`PRAGMA integrity_check` 返回 `ok`，会话数为 0。此批合成数据没有媒体；媒体字节完整性另由 PNG 备份恢复集成测试覆盖。

## RFC 0002：账号与私有访问

实现于 2026-10-24，按用户最终决定收敛为邮箱单渠道，短信和手机移出本次范围。真实账号、发件人、收件人、测试号码、Bucket 与运行密钥不进入本记录。

| 范围 | 当前证据 |
| --- | --- |
| 登录限制 | 删除 `public_read` 放行；匿名文章、Tag、搜索、历史、引用、媒体 GET／HEAD 均须登录；回归测试覆盖旧设置残留 |
| 三级角色 | 系统管理员、管理员、普通用户及只读标记；最近重新验证、最后系统管理员保护、禁用和降级撤销会话有测试 |
| 验证码 | 用途／目标／会话绑定、HMAC 摘要、联系方式 AES-GCM 加密、一次性事务消费、失败次数、并发邀请消费有测试 |
| 邮箱 | 用户指定的地址真实收到验证码，并在浏览器完成邀请加入、创建普通成员和登录，账号页显示脱敏绑定 |
| 手机 | 不启用；正式启动不加载短信配置，页面移除入口，运行身份移除发送权限，停用渠道的旧码不可消费 |
| 费用 | 最终选平台短信按量发送，不买套餐；默认全站每日 20／UTC 自然月 100 次，单目标每小时 5／每日 10 次，60 秒重发、5 次验错；额度保存在 SQLite，失败／超时也占额度 |
| OSS | 经授权，浏览器上传合成 PNG 和 MP4；发布后图片解码成功，2 秒视频实际播放并操作进度条；保留历史版本媒体 |
| 媒体授权 | 实际 OSS-backed Range 返回 206；退出会话后 GET／HEAD 返回 401；原始 OSS 对象匿名访问返回 403 |
| 真实 OSS 备份恢复 | 空目录恢复成功；4 个媒体对象字节与授权的合成文件一致，数据库完整性为 `ok`，会话／邀请／挑战均清除 |
| 升级恢复 | 显式选择旧系统管理员，原只读权限保留，旧会话失效，迁移前备份；独立身份密钥恢复及 CLI 管理员恢复有测试 |
| 管理 | 成员管理、邀请状态及撤销、本人会话撤销、系统管理员脱敏审计及配置状态均已提供 |

真实联调修复了两处问题：SDK 默认连接没有使用本机代理，导致上传后元数据校验超时；异步插入第二个媒体时替换了选中的第一个媒体。现已使用标准代理连接，并在选区后插入媒体，浏览器重测同时保留图片和视频。

构建后客户端延迟加载资源时，如果遇到发行版本更新造成的模块失效，会进行一次受限刷新；本地草稿仍按原有机制保存。测试环境与正式资料独立，未自动导入旧站个人文章。

限量复核：短信默认值、CLI 与私有运行配置统一为每天 20 次、UTC 自然月 100 次；达到额度不再调用供应商。新增日／月额度回归测试，验证投递失败仍占额度，新应用实例重新加载同一数据库后仍受限。此为单 Wiki 数据目录的应用限量，云账户级 PNVS 限量尚未确认。

最终邮箱单渠道修订：移除 PNVS 生产发送适配器和 SDK 依赖；现有数据库结构兼容保留。真实邮箱邀请注册／登录、OSS 图片视频及备份恢复证据继续有效。短信验收不再属于本次目标；历史费用比较仅供决策追溯。

最终验证：Go 竞态测试、vet、模块校验、Vue 类型检查与生产构建通过。实际服务渠道状态为邮箱启用、手机停用。浏览器验证 360px 账号页无横向溢出、无手机入口；新配置重启后真实 OSS 鉴权与 Range 回归通过。真实密钥、联系方式、云资源标识扫描通过，私有资料不纳入提交。

## 响应式与邀请入口整体复验

- 修复未登录时沿用侧栏网格导致表单落入窄列的问题。登录页独立单栏居中，手机表单随可用宽度变化，桌面最大宽度 460px。
- 手机页头改为两行网格，320px 下不再因三行换行裁切标志；窄屏写文章入口保留在导航菜单。长昵称不撑开页头，成员行可换行。
- 浏览器验证 320、360、600、760、761、768、820、1024、1440、1920px：登录页 10 组；首页、时间线、标签目录、标签列表、搜索、草稿、管理、账号、文章、历史、编辑器共 110 组。核对实际视口宽度、横向溢出、控件边界与页头位置，并人工查看手机、平板、桌面截图。
- 操作手机菜单、邮箱／密码切换、邀请创建备注与撤销。直接打开真实本地邀请链接后进入加入页，无手填凭证；修复初始路由尚未就绪时清掉邀请参数的竞态。普通登录页移除手动加入按钮。
- 自动化覆盖备注长度、创建与使用记录、无原始令牌泄露、已消费链接不可再次发码；已有并发消费测试通过。
- 数据库升级至 schema 6，升级前自动备份。实际 OSS 备份恢复到空目录后完整性正常，4 个媒体保留，会话、挑战和邀请清除；实际 Range、退出后拒绝读取、OSS 匿名拒绝回归通过。
- Go 竞态测试、vet、Vue 类型检查及生产构建通过。邮箱真实收码沿用此前独立验收，本轮未重复发送验证码。以上为桌面浏览器尺寸模拟，尚未在 iOS、Android、iPad 真机测试输入法与触摸体验。

## 无密码账号与成员禁用

- 最终账号页只展示成员信息、只读邮箱、登录记录和退出；移除密码区、绑定区、更换表单和操作下拉框。浏览器检查 320–1920px 十种宽度，默认页面无输入框、无横向溢出。
- 所有成员使用邮箱验证码登录。旧密码登录、改密及密码验证返回 410。初始化须服务器凭证和邮箱验证码；旧管理员通过服务器生成的一小时一次性恢复链接验证邮箱后接回原账号，保留用户 ID。相关流程有自动化测试。
- 邮箱验证码登录后的五分钟内可进行敏感管理操作，超过后重新登录确认。升级到 schema 7 自动备份、清空旧密码摘要、撤销旧会话和未用验证码；本地实际升级后数据库完整性正常、密码摘要数量为零。
- 管理页提供明确的禁用／解除禁用按钮，记录独立审计事件。自动化验证旧会话、未消费验证码、媒体访问立即失效，注册白名单不能绕过禁用；解除后必须使用新验证码，旧登录不恢复。虚构成员的按钮操作已在浏览器验证。
- schema 7 真实 OSS 备份恢复演练通过，4 个媒体保留，恢复副本无会话、挑战或邀请。真实邮箱历史验收继续有效；本轮 UI 验证使用独立虚构数据和捕获发送器，未向真实用户额外发送邮件。
